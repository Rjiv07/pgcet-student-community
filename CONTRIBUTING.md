# Contributing

Thanks for helping build PGCET Student Community. The project works best when students share reliable resources and improve them together.

## Ways to contribute

- Report an incorrect or outdated link
- Suggest a useful PGCET, admissions, syllabus or career resource
- Share a college/event/project opportunity with source details
- Improve documentation, content design, accessibility, or code
- Review submissions for clarity and reliability

## Content rules

- Provide the original source URL and a checked date for official/current facts.
- Separate official information from personal student experiences.
- Do not submit personal data about other people without permission.
- Do not make unsupported placement, salary, ranking, admissions, or exam claims.
- Student stories should be shared voluntarily with clear permission to publish.
- Do not upload pirated books, paid coaching materials, or content you do not have rights to redistribute.
- Report errors and privacy concerns promptly.

## Code contributions

1. Open an issue describing the problem or proposed change.
2. Keep pull requests focused and small enough to review.
3. Follow the existing design tokens and component conventions.
4. Run the build/type checks and relevant tests before opening a pull request.
5. Include screenshots for meaningful UI changes, including mobile where applicable.
6. Do not add secrets, credentials, private student details, or unsupported third-party data collection.

## Review

Contributions may be edited, deferred, or declined to protect students and the reliability of the site. Submission does not guarantee publication.
