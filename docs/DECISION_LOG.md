# Decision Log

Record material decisions here so that project direction isn't re-litigated without new evidence.

## D-001 — Visual identity
- Status: Approved
- Decision: editorial premium, light-first, balanced Gen Z; navy/ivory/teal/terracotta palette; Manrope + Inter.
- Revisit only for accessibility failures or tested user feedback.

## D-002 — Product mission
- Status: Approved
- Decision: serve the whole journey from PGCET preparation and admissions through college learning, projects, campus life, internships and placements, then encourage students to help future batches.

## D-003 — Launch audience
- Status: Approved
- Decision: begin with Karnataka PGCET and MCA/MBA/M.Tech pathways; structure content to broaden later.

## D-004 — Community platform relationship
- Status: Approved
- Decision: Reddit and Telegram are conversation channels; the website is the structured knowledge base. Reddit discussions may be linked selectively. No scraping or automated summarisation in the initial release.

## D-005 — Initial technical approach
- Status: Proposed for implementation
- Decision: static-first React + Vite + TypeScript + Tailwind frontend; no backend, authentication or database in the foundation sprint.

## D-006 — Avoiding rework
- Status: Approved
- Decision: define product scope, visual tokens, route map, content boundaries and acceptance criteria before implementation. Use a feature branch, shared components, typed content and explicit review gates. Avoid rewriting working code without a specific issue and agreed reason.
