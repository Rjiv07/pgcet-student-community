# Sprint 005 — Verified resources and student contributions

## Product goal

Serve both PGCET aspirants and current MCA students through one connected journey: prepare, navigate admissions, learn in college, build projects, and prepare for work.

## Contribution workflow delivered

GitHub issue forms now accept three types of submissions:
- **Resource suggestion** — original source URL, audience, resource type, and usefulness.
- **Student experience** — stage of the journey, firsthand account, optional supporting links, and explicit consent to review.
- **Correction report** — page/resource URL, issue type, and supporting details.

The website's Contribute page links to the issue-form chooser. Submissions are public GitHub issues and are proposals for review, not automatic publication. The forms remind contributors to remove private information. Do not solicit sensitive identity documents or publish student experiences without consent.

## Editorial review checklist

Before a suggestion becomes a website resource:
1. Open the original source and confirm it is accessible and relevant.
2. Prefer the responsible authority or institution for official policy, exam, eligibility, deadline, and admission claims.
3. Record the source URL, source owner, applicable exam/course/year, reviewer, and date checked.
4. Label content as **official**, **community guide**, or **student experience**; never make a personal account look like an official statement.
5. For time-sensitive facts, re-check the source before publishing and add a visible last-checked date to the resource.
6. For college comparisons, distinguish published facts from firsthand reports; don't invent fees, placements, rankings, facilities, or outcomes.
7. Check copyright, permissions, consent, accessibility, and privacy before publication.
8. Close the loop with the contributor: accepted, needs clarification, or not accepted, with a short reason.

## Initial authoritative starting point

- **Karnataka Examinations Authority (KEA):** https://cetonline.karnataka.gov.in/kea/ — start here for official Karnataka PGCET notices and admission information. Always open the latest applicable notification; this guide does not claim any particular date, eligibility rule, result, or counselling round is currently active.

Other resources should be added only after their official ownership and relevance have been checked. Do not label a link “official” merely because it looks professional or is widely shared.

## Scope boundaries

- This sprint adds a lightweight GitHub-based submission path; it does not add accounts, a database, file uploads, or an in-site moderation dashboard.
- GitHub issues are public. Contributors must not submit sensitive personal data or documents.
- No automated Reddit scraping, reposting, or student-experience publication.
- A reviewer must verify each submission before incorporating it into the website.

## Acceptance checks

- [ ] Each issue form clearly asks for the information needed to review the submission.
- [ ] Student experience form records consent for review and warns that issues are public.
- [ ] Contribute page links to the GitHub issue-form chooser.
- [ ] Existing resource links and routes continue to work.
- [ ] Type-check, lint, and production build pass before merge.
