# Sprint 004 — Starter Resource Library

## Purpose
Seed the resource directory with genuinely useful checklists so the first release has practical content, without fabricating current exam notices, college facts, event listings, or placement statistics.

## Starter guides
- Syllabus verification
- Admissions next steps
- Semester resource sharing
- Campus event submission
- Project portfolio checklist
- Internship/placement opportunity safety
- Student journey guide
- Official KEA starting point

## Content classification
The checklists are community-authored starter guidance, not official policy. They are labelled as starter content and should be reviewed and expanded as the community contributes authoritative links and experience. Time-sensitive facts must carry an original source and review date.

## Homepage content strategy
Show a small curated selection of useful resources on the homepage; keep the complete searchable library on the Learn & Resources page. This avoids turning the landing page into a long catalogue.

## Not included
No user accounts, uploads, backend, live job board, automatic Reddit import, or claims of current exam/counselling dates.
